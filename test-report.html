Test 1: Repository Name Exposure

HIGH PRIORITY: Success/error notifications expose repository names

When version fetch succeeds, notification shows: "Fetched version 1.2.3 from farmartos-backend"

This defeats the purpose of hiding repos in env variables. Repo names should be masked.

Test 2: Branch Name Assumption

HIGH PRIORITY: Code assumes 'main' branch

Line 62: const branch = 'main';
